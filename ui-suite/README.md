# 输入法全套 UI 界面系统 (IME UI Suite)

现代化、全功能、多端适配且支持真实交互的完整输入法 UI 组件与演示沙盒。

## 🌟 核心特性与包含的所有界面

本套 UI 系统完整覆盖了现代输入法产品的所有核心界面与交互流：

| 序号 | 界面名称 | 界面核心特性与交互 |
| :--- | :--- | :--- |
| 1 | **拼音 26 键主键盘** | QWERTY 布局、长按上标字符、按键放大镜气泡 (Popup Preview)、拼音预编辑与候选词滑动条 |
| 2 | **拼音 9 键九宫格** | 经典九宫数字键盘、数字-字母多重映射、左侧拼音组合多级筛选分词栏 |
| 3 | **英文与大小写键盘** | 首字母大写切换、Caps Lock 锁定、英文单词前缀实时补全预测 |
| 4 | **数字专用键盘** | 大按键金融/数字快速输入、常用符号聚合 |
| 5 | **符号大全分类面板** | 7 大符号分类（常用、中文标点、英文标点、数学运算、数字序号、特殊图形、网络颜文字） |
| 6 | **Emoji 与贴纸表情面板** | 6 大 Emoji 分类（表情、手势、人物、动物、食物、日常）、Meme 动图贴纸库 |
| 7 | **Canvas 智能手写板** | HTML5 Canvas 贝塞尔平滑笔锋渲染、九宫辅助网格、笔画撤销、一键重写清空、汉字模拟识别候选 |
| 8 | **AI 动态语音输入面板** | Canvas 实时声波频谱动态脉冲动画、多语种/方言切换（普通话/粤语/英语/四川话）、流式转写与上屏 |
| 9 | **剪贴板与快捷短语面板** | 历史剪贴记录卡片、图钉置顶、分类懒人常用语（问候语、商务办公、常用收件地址模板） |
| 10 | **桌面端悬浮状态栏** | 可自由拖拽移动、中/英切换、中/英标点切换、全/半角切换、横排/竖排候选模式切换 |
| 11 | **桌面端光标吸附候选框** | 拼音拼写分词提示、多音字/单字候选高亮、翻页器、横排/竖排灵活切换 |
| 12 | **设置与个性化中心** | Web Audio API 仿真按键音效（机械青轴 / iOS 轻触音）、模糊音纠错开关、按键气泡开关 |

```
    ├── handwriting.js      # Canvas 平滑笔迹引擎与笔画识别

```

## 🚀 启动与使用方式

由于本项目采用纯原生标准（HTML5 + CSS3 + ES6 Modules），无需安装复杂的 Node.js 或构建工具：

1. 直接在支持 ES Module 的现代浏览器中打开 `index.html`（建议通过本地静态 HTTP 服务器，如 VS Code Live Server 或 Python `python -m http.server 8080` 打开）。
2. 在页面中：
   - 可以直接用**物理键盘**敲击打字（例如输入 `nihao`，按空格或数字 `1` 选词上屏）。
   - 可以在中间的**手机真机模型**中点击软键盘打字、切换 9键、符号、Emoji、手写与语音。
   - 可以在右侧体验**桌面端悬浮状态栏**与**光标候选词框**的横竖排切换及拖拽。

# App 界面开发规范

适用：首页、偏好设置、按键皮肤、模糊音设置，以及这些页面共用的按钮、导航和开关。键盘输入区保留既有参考设计。所有后续界面修改须先按本表选值，再检查实际布局；不随手添加新的间距、字号或固定坐标。

## 依据与单位

参考 Apple [Layout](https://developer.apple.com/design/human-interface-guidelines/layout)、[Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)、[Toggles](https://developer.apple.com/design/human-interface-guidelines/toggles) 和 [Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)。安全区、布局对齐、可辨认的操作层级、按钮按下反馈、字体放大和不只靠颜色表达状态是原则。

Apple 的 pt 不是 Android 的 dp/sp。下面是本项目在 Android 上的具体实现值，不把所有数值说成 Apple 强制规定。尺寸/间距用 dp、文字用 sp；禁止用物理 px 定位界面。复用 `ImeDesignTokens.kt` 的几何/间距/文字令牌与 `values/dimens.xml` 同名资源；XML 用资源，动态 View 用令牌。

## 布局尺寸与位置

| 项目 | 数值 | 放置及对齐规则 |
| --- | --- | --- |
| 系统安全区 | Android 实际 Insets | Activity 扣除状态栏、导航栏和屏幕切口一次；内容不覆盖系统区域 |
| 内容宽度 | 最多 600dp | 宽屏居中；窄屏取可用宽度，不能套用键盘的 390dp 参考画布 |
| 页面左右边距 | 16dp | 相对于上述内容区；首页卡片、输入框、主按钮和设置行共用左右边界 |
| 页面顶部留白 | 16dp | 首页从安全区起算；设置页从导航栏下方起算 |
| 导航栏 | 56dp 高 | 返回按钮在左侧，48×48dp 点击区垂直居中；左右内边距 16dp |
| 导航标题 | 16sp | 返回按钮之后，垂直居中；单行，长标题省略，读屏保留完整名称 |
| 首页品牌 | 48×48dp 图标、20sp 名称 | 左对齐页面边界，图文间隔 12dp；副标题 12sp，与名称间隔 4dp |
| 分组间距 | 24dp | 上一组内容结束到下一组标题；页首第一组直接跟随顶部留白 |
| 分组标题 | 12sp | 与行内容左内边距对齐；标题到控件 8dp |
| 同组设置行/步骤间距 | 8dp | 保持独立按键表面的间隙；键盘字母键继续用既有 6dp 间隙 |
| 行内左右边距 | 16dp | 图标或标签左对齐；开关、数值或导航箭头右对齐 |
| 行内上下边距 | 8dp | 普通设置行及首页步骤至少 64dp 高；内容换行时自动增高 |
| 设置行图标 | 24×24dp | 垂直居中，与文字相隔 12dp；装饰图标不重复进入读屏焦点 |
| 首页步骤标记 | 28×28dp | 与文字相隔 12dp，垂直居中；语音权限使用同尺寸标记 |
| 主文字/说明 | 14sp / 11–12sp | 标签与说明间隔 4dp；保留系统字体放大，说明允许换行 |
| 文字到末端控件 | 至少 12dp | 不让标签贴住开关或箭头；不得靠压缩字号塞入固定宽度 |
| 横排分段选项 | 48dp 点击高度，34dp 可见轨道 | 轨道垂直居中；内边距 2dp；各选项等宽。正常横排行中标签与选项占剩余宽度的 1:2，中间相隔 12dp |
| 纵排分段选项 | 每项至少 48dp，宽度填满行内容区 | 标签下方相隔 8dp；选项等宽，文字居中，选中状态同时突出文字与表面 |
| 滑杆 | 至少 48dp 高的操作区 | 正常横排标签宽 80dp，后接 12dp 间距；滑杆填充剩余宽度，右侧数值至少 48dp 宽。上下排列时标签和数值同排，滑杆位于其下方 |
| 导航箭头 | 图标 24dp，所在区域高 48dp | 位于行尾并垂直居中；整行可点击，不作为独立按钮 |
| 主操作按钮 | 52dp 高、胶囊形 | 蓝底白字；首页固定在安全区底部上方 16dp，左右边界与卡片一致 |
| 次操作按钮 | 至少 48dp 高 | 浅强调色背景，与主按钮形成层级；相邻操作间隔 12dp |
| 输入框 | 至少 56dp 高 | 内边距左右 16dp、上下 8dp；多行内容增高；左右与卡片对齐 |
| 开关 | 轨道 51×31dp、白色滑块 27dp | 位于行尾，垂直居中；滑块与轨道端部间隔 2dp，移动 20dp；点击区至少 48dp 高 |
| 表面圆角 | 8dp | 白色按键表面和键盘一致；按钮/开关是胶囊，不能把所有卡片变成胶囊 |

## 宽度与字体变化

- 正常字号且可用窗口宽度至少 360dp：设置标签在左，分段选项/滑杆/数值在右，垂直居中。
- 窗口不足 360dp，或字体缩放达到 1.2：标签在上，选项/滑杆在下；滑杆数值与标签同排，数值保持单行。
- 字体缩放达到 1.6：三项分段选项改为纵向排列，避免长标签挤入三个窄列。每项仍至少 48dp，可通过真实点击选择。
- 宽屏仅扩展到 600dp；不把开关拉宽，不把主按钮拉到整块屏幕。单手键盘设置只改变输入区，不能缩窄 App 设置页。
- 2 倍字体允许页面自然变长并滚动；禁止截掉说明、压缩字号或把按钮放到屏幕外。主操作与系统导航区不能重叠。

## 状态与交互

- 主按钮、次按钮、输入框必须有按下或聚焦反馈；禁用状态同时改变外观和可操作性。
- 开关以绿色/灰色轨道和滑块左右位置共同表达状态；设置立即保存。Android 读屏节点标记为 Switch，提供 checkable/checked 与状态说明。
- 导航行整行可点击，装饰箭头不形成第二个焦点；行尾开关不与文字重叠。
- 首页返回、皮肤和模糊音二级页的返回沿既有页面栈，不能依靠图标外观猜测目的地。

## 验收与可重复工件

运行 `scripts/beta4_e2e.py`：真实点击设置和按钮，核对实际 UI XML 的尺寸、左右边界、步骤间隙、Button/Switch 语义；检查浅色、深色、320dp 的 1.3/2.0 倍字体和宽屏。保留截图、XML、JSON 和日志，再人工检查换行、控件位置与状态。测试命令和语音验收范围见 `BETA4_VOICE.md`。不新增单元测试，不用只核对源码常量的断言代替实际界面验收。
